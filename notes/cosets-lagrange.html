Cosets and Lagrange's theorem

Definition 3.2 (Left cosets). Let \(H\le G\) and \(g\in G\). The left coset of \(H\) by \(g\) is \(gH=\{gh : h\in H\}\), and \(G/H=\{gH : g\in G\}\) is the set of all left cosets. Right cosets \(Hg=\{hg : h\in H\}\) and \(H\backslash G=\{Hg : g\in G\}\) are defined in the same way.

Lemma 3.3 (Cosets partition \(G\)). If \(H\le G\), then

  1. \(G=\bigcup_{gH\in G/H} gH\), and
  2. if \(g_1H\cap g_2H\neq\varnothing\), then \(g_1H=g_2H\).

Proof. (1) Every \(g\in G\) lies in \(gH\), since \(e\in H\). So \(G\subseteq\bigcup gH\), and the reverse inclusion is clear.
(2) Take \(k\in g_1H\cap g_2H\), so \(k=g_1h_1=g_2h_2\) for some \(h_1,h_2\in H\). Then \(g_1=g_2h_2h_1^{-1}\) with \(h_2h_1^{-1}\in H\). Hence for any \(h\in H\), \(g_1h=g_2(h_2h_1^{-1}h)\in g_2H\), so \(g_1H\subseteq g_2H\). By symmetry \(g_2H\subseteq g_1H\), so \(g_1H=g_2H\). \(\blacksquare\)

Lemma 3.4 (Cosets have the same size). If \(H\le G\) and \(g\in G\), then \(h\mapsto gh\) is a bijection \(H\to gH\). In particular \(|gH|=|H|\).

Proof. The map \(gH\to H\), \(gh\mapsto g^{-1}(gh)=h\), is an inverse. \(\blacksquare\)

Definition 3.5 (Index). The index of \(H\le G\) is \([G:H]=|G/H|\), the number of left cosets.

Theorem 3.6 (Lagrange's theorem). If \(H\le G\) and \(|G|<\infty\), then $$|G|=[G:H]\cdot|H| .$$

Proof. The left cosets partition \(G\) (Lemma 3.3) and each has size \(|H|\) (Lemma 3.4), so $$|G|=\sum_{gH\in G/H}|gH|=\sum_{gH\in G/H}|H|=[G:H]\cdot|H|. \qquad\blacksquare$$

Corollary 3.8. If \(|G|<\infty\) and \(g\in G\), then \(g^{|G|}=e\).

Proof. Since \(o(g)=|\langle g\rangle|\), Lagrange's theorem gives \(|G|=k\,o(g)\) for some \(k\in\mathbb Z\). So \(g^{|G|}=g^{k\,o(g)}=\big(g^{o(g)}\big)^k=e^k=e\). \(\blacksquare\)

Corollary 3.9. If \(|G|\) is prime, then \(G\) is cyclic and every \(g\neq e\) generates it.

Proof. Take \(g\neq e\). By Lagrange's theorem \(o(g)\mid |G|\), so \(o(g)=1\) or \(o(g)=|G|\) because \(|G|\) is prime. Since \(g\neq e\), \(o(g)=|G|\), so \(G=\langle g\rangle\) is cyclic. \(\blacksquare\)

Theorem 3.11 (Fermat–Euler). Let \(x,n\in\mathbb Z\). If \(\gcd(x,n)=1\), then $$x^{\varphi(n)}\equiv 1 \pmod n,$$ where \(\varphi(n)=\big|\{x\in\mathbb Z_n : \gcd(x,n)=1\}\big|\) is Euler's totient function.

Proof. By Bézout's lemma, \(x\) has an inverse modulo \(n\) if and only if \(\gcd(x,n)=1\). So \(\mathbb Z_n^{*}=\{x\in\mathbb Z_n : \gcd(x,n)=1\}\) is a group under multiplication modulo \(n\), with \(|\mathbb Z_n^{*}|=\varphi(n)\). By Corollary 3.8, \(x^{|\mathbb Z_n^{*}|}\equiv 1 \pmod n\), that is, \(x^{\varphi(n)}\equiv 1 \pmod n\). \(\blacksquare\)
