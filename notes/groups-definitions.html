Binary operation

A binary operation on a set \(X\) is a function \(\cdot : X\times X\to X\).

Bijection

A map \(f:X\to Y\) is a bijection if it has an inverse \(g:Y\to X\) with \(g\circ f=\mathrm{id}_X\) and \(f\circ g=\mathrm{id}_Y\).

Subgroup

\(H\subseteq G\) is a subgroup, written \(H\le G\), if \(e\in H\), \(ab\in H\) for all \(a,b\in H\), and \(a^{-1}\in H\) for all \(a\in H\). A subgroup is itself a group.

Generated subgroup and generating set

For \(X\subseteq G\), the subgroup generated by \(X\) is $$\langle X\rangle=\bigcap_{X\subseteq H\le G}H,$$ the smallest subgroup containing \(X\). If \(G=\langle X\rangle\), then \(X\) generates \(G\) (is a generating set): every \(g\in G\) is a product \(x_1^{\pm1}x_2^{\pm1}\cdots x_n^{\pm1}\) with \(x_i\in X\).

Isometry

For \(X\subseteq\mathbb C\), an isometry of \(X\) is a bijection \(f:X\to X\) that preserves distance: \(|f(x)-f(y)|=|x-y|\) for all \(x,y\in X\).

Dihedral group

For \(n\ge3\), let \(X_n\subseteq\mathbb C\) be the regular \(n\)-gon with vertices \(e^{2\pi ik/n}\), \(k=0,\dots,n-1\). The dihedral group is \(D_{2n}=\operatorname{Isom}(X_n)\), and \(|D_{2n}|=2n\).

Kite lemma

Let \(x_1,x_2,y_1,y_2\in\mathbb C\). If \(|y_1-x_1|=|y_2-x_1|\) and \(|y_1-x_2|=|y_2-x_2|\), then \(x_2-x_1\) is perpendicular to \(y_2-y_1\).

Proof. Expanding, \(|y_1-x|^2=|y_2-x|^2\) is equivalent to \(\operatorname{Re}\big((y_2-y_1)\overline{x}\big)=\tfrac12\big(|y_2|^2-|y_1|^2\big)\). Both \(x_1\) and \(x_2\) satisfy this, so subtracting gives \(\operatorname{Re}\big((y_2-y_1)\overline{(x_2-x_1)}\big)=0\), which says exactly that \(x_2-x_1\perp y_2-y_1\). Geometrically: \(x_1\) and \(x_2\) both lie on the perpendicular bisector of \(y_1y_2\). \(\blacksquare\)

3 point lemma

Let \(X\subseteq\mathbb C\) and \(f\in\operatorname{Isom}(X)\). If \(f\) fixes three non-collinear points \(x_1,x_2,x_3\in X\), then \(f=\mathrm{id}_X\).

Proof. Suppose \(f(y)\neq y\) for some \(y\in X\). For \(i=1,2,3\), \(|f(y)-x_i|=|f(y)-f(x_i)|=|y-x_i|\), since \(f\) fixes \(x_i\) and preserves distance. By the kite lemma with \(y_1=y\), \(y_2=f(y)\): both \(x_2-x_1\) and \(x_3-x_1\) are perpendicular to the non-zero vector \(f(y)-y\). So they are parallel, and \(x_1,x_2,x_3\) are collinear, a contradiction. \(\blacksquare\)

Homomorphism

A map \(\varphi:G\to H\) between groups is a homomorphism if \(\varphi(gg')=\varphi(g)\varphi(g')\) for all \(g,g'\in G\). Its image is \(\operatorname{im}\varphi=\{\varphi(g):g\in G\}\) and its kernel is \(\ker\varphi=\{g\in G:\varphi(g)=e_H\}\).

Isomorphism

A homomorphism \(\varphi:G\to H\) that is a bijection is an isomorphism, and we write \(G\cong H\). A homomorphism \(\varphi:G\to H\) is an isomorphism if and only if \(\operatorname{im}\varphi=H\) and \(\ker\varphi=1_G\) (Proposition 2.10).

Cosets

For \(H\le G\) and \(g\in G\), the left coset is \(gH=\{gh:h\in H\}\), and \(G/H\) is the set of left cosets. The left cosets partition \(G\), and \(h\mapsto gh\) is a bijection \(H\to gH\), so every coset has \(|H|\) elements.

Index

The index of \(H\le G\) is \([G:H]=|G/H|\), the number of left cosets. By Lagrange, \(|G|=[G:H]\,|H|\) when \(G\) is finite.

Orbit

If \(G\) acts on \(X\) and \(x\in X\), the orbit of \(x\) is \(Gx=\{gx:g\in G\}\).

Stabiliser

If \(G\) acts on \(X\) and \(x\in X\), the stabiliser of \(x\) is \(\operatorname{Stab}_G(x)=\{g\in G:gx=x\}\), a subgroup of \(G\).

Cauchy's theorem

If \(|G|<\infty\) and \(p\) is a prime dividing \(|G|\), then \(G\) has an element of order \(p\).

Why it matters. Lagrange says the order of every element divides \(|G|\), but the converse fails in general: \(|A_4|=12\), yet \(A_4\) has no element of order \(6\). Cauchy says the converse holds for primes. For example, \(D_{10}\) has an element of order \(2\) (a reflection) and one of order \(5\) (a rotation).

1. Build a set. Let \(X=\{(g_1,\dots,g_p): g_1g_2\cdots g_p=e\}\). Choosing \(g_1,\dots,g_{p-1}\) freely forces \(g_p=(g_1\cdots g_{p-1})^{-1}\), so \(|X|=|G|^{p-1}\), which is divisible by \(p\).

2. Let \(C_p\) rotate the tuples. \(t^k(g_1,\dots,g_p)=(g_{k+1},\dots,g_p,g_1,\dots,g_k)\). This stays in \(X\): with \(a=g_1\cdots g_k\), \(b=g_{k+1}\cdots g_p\), \(ab=e\) gives \(b=a^{-1}\), so \(ba=e\).

3. Orbits have size \(1\) or \(p\). By orbit–stabiliser each orbit's size divides \(|C_p|=p\), which is prime.

4. Count. If \(\ell\) orbits have size \(1\) and \(m\) have size \(p\), then \(|G|^{p-1}=\ell+pm\). The left side is divisible by \(p\), so \(p\mid\ell\).

5. Find the element. A size-\(1\) orbit is a constant tuple \((g,\dots,g)\) with \(g^p=e\). \((e,\dots,e)\) is one, so \(\ell\ge1\), and \(p\mid\ell\) gives \(\ell\ge p\ge2\). So some \(g\neq e\) has \(g^p=e\), hence \(o(g)=p\). \(\blacksquare\)

Conjugation

For \(g,h\in G\), the element \(hgh^{-1}\) is the conjugate of \(g\) by \(h\).

Conjugacy class

The conjugacy class of \(g\in G\) is \(\operatorname{ccl}(g)=\{hgh^{-1}:h\in G\}\), its orbit under the conjugation action \(h\ast\gamma=h\gamma h^{-1}\).

Centraliser

The centraliser of \(g\) is \(C_G(g)=\{h\in G:hgh^{-1}=g\}=\{h\in G:hg=gh\}\), the elements commuting with \(g\). It is the stabiliser of \(g\) under conjugation.

Centre

The centre of \(G\) is \(Z(G)=\{g\in G:hgh^{-1}=g\text{ for all }h\in G\}=\bigcap_{g\in G}C_G(g)\), the elements commuting with everything.

Riemann sphere

The Riemann sphere is \(\mathbb C_\infty=\mathbb C\cup\{\infty\}\). Stereographic projection identifies it with a sphere, with \(\infty\) as the north pole.

Circle in \(\mathbb C_\infty\). Either a Euclidean circle \(|z-a|=r\) (\(a\in\mathbb C\), \(r>0\)), or \(\ell\cup\{\infty\}\) for a straight line \(\ell=\{z:|z-a|=|z-b|\}\) (\(a\neq b\)). So lines count as circles through \(\infty\).

Möbius transformation

For \(a,b,c,d\in\mathbb C\) with \(ad-bc\neq0\), the Möbius transformation \(\mu:\mathbb C_\infty\to\mathbb C_\infty\) is \(\mu(z)=\dfrac{az+b}{cz+d}\), with \(\mu(-d/c)=\infty\) and \(\mu(\infty)=a/c\) if \(c\neq0\), and \(\mu(\infty)=\infty\) if \(c=0\). Under composition these maps form the Möbius group \(\mathcal M\); the inverse of \(z\mapsto\frac{az+b}{cz+d}\) is \(z\mapsto\frac{dz-b}{-cz+a}\).

Fixed point. If \(f:X\to X\) is a permutation, \(x\) is a fixed point of \(f\) if \(f(x)=x\). For example \(z\mapsto z+1\) fixes only \(\infty\), and \(z\mapsto 2z\) fixes \(0\) and \(\infty\).

Three-point lemma. If \(\mu\in\mathcal M\) fixes three distinct points of \(\mathbb C_\infty\), then \(\mu=\mathrm{id}\).

Proof. A fixed point \(w\) satisfies \(w=\frac{aw+b}{cw+d}\). If \(\infty\) is fixed, then \(c=0\), and the other two fixed points are roots of \((a-d)w+b=0\). A linear equation with two roots is trivial, so \(a=d\), \(b=0\), and \(\mu=\mathrm{id}\). Otherwise all three fixed points are in \(\mathbb C\) and are roots of \(cw^2+(d-a)w-b=0\). A quadratic with three roots is trivial, so \(c=0\), \(a=d\), \(b=0\), and \(\mu=\mathrm{id}\). \(\blacksquare\)

Generators. \(\mathcal M\) is generated by \(\alpha_a(z)=az\) (\(a\neq0\)), \(\beta_b(z)=z+b\) (\(b\in\mathbb C\)) and \(\gamma(z)=1/z\).

Proof. Take \(\mu\in\mathcal M\) and let \(z_1=\mu(0)\), \(z_2=\mu(1)\), \(z_3=\mu(\infty)\). Step 1: if \(z_3=\infty\) let \(\mu_1=\mathrm{id}\); otherwise let \(\mu_1=\gamma\circ\beta_{-z_3}\), that is \(z\mapsto\frac{1}{z-z_3}\). Either way \(\mu_1(z_3)=\infty\). Step 2: let \(\mu_2=\beta_{-\mu_1(z_1)}\), so \(\mu_2\mu_1\) sends \(z_1\mapsto0\) and \(z_3\mapsto\infty\). Step 3: \(z_2''=\mu_2\mu_1(z_2)\) is neither \(0\) nor \(\infty\) (the points are distinct), so let \(\mu_3=\alpha_{1/z_2''}\). Then \(\nu=\mu_3\mu_2\mu_1\) sends \(z_1,z_2,z_3\) to \(0,1,\infty\). So \(\nu\circ\mu\) fixes \(0,1,\infty\), and by the three-point lemma \(\nu\circ\mu=\mathrm{id}\). Hence \(\mu=\mu_1^{-1}\mu_2^{-1}\mu_3^{-1}\), a product of generators, since \(\alpha_a^{-1}=\alpha_{1/a}\), \(\beta_b^{-1}=\beta_{-b}\) and \(\gamma^{-1}=\gamma\). \(\blacksquare\)

Triple transitivity

For any two triples of distinct points \(z_1,z_2,z_3\) and \(w_1,w_2,w_3\) in \(\mathbb C_\infty\), there is a \(\mu\in\mathcal M\) with \(\mu(z_i)=w_i\) for \(i=1,2,3\). By the three-point lemma \(\mu\) is unique, so \(\mathcal M\) acts on \(\mathbb C_\infty\) sharply triply transitively.

Proof. Let \(\alpha(z)=\dfrac{z_2-z_3}{z_2-z_1}\cdot\dfrac{z-z_1}{z-z_3}\) (modified suitably if some \(z_i=\infty\)). Then \(\alpha\in\mathcal M\) sends \(z_1,z_2,z_3\) to \(0,1,\infty\). Define \(\beta\) the same way for \(w_1,w_2,w_3\). Then \(\mu=\beta^{-1}\circ\alpha\) sends each \(z_i\) to \(w_i\). If \(\mu'\) also works, then \(\mu^{-1}\mu'\) fixes \(z_1,z_2,z_3\), so \(\mu'=\mu\). \(\blacksquare\)

Cross ratio

For distinct \(z_1,z_2,z_3,z_4\in\mathbb C_\infty\), let \(\alpha\) be the unique Möbius map with \(\alpha(z_1)=0\), \(\alpha(z_2)=1\), \(\alpha(z_3)=\infty\). The cross ratio is $$[z_1,z_2,z_3,z_4]=\alpha(z_4)=\frac{(z_4-z_1)(z_2-z_3)}{(z_4-z_3)(z_2-z_1)} .$$ Four points lie on a circle in \(\mathbb C_\infty\) if and only if their cross ratio is in \(\mathbb R_\infty=\mathbb R\cup\{\infty\}\).

Direct product theorem

Direct product. For groups \(G,H\), the direct product is \(G\times H=\{(g,h):g\in G,\,h\in H\}\) with \((g_1,h_1)(g_2,h_2)=(g_1g_2,\,h_1h_2)\). The identity is \((e_G,e_H)\) and \((g,h)^{-1}=(g^{-1},h^{-1})\).

Theorem. Let \(H_1,H_2\le G\) with (1) \(H_1\cap H_2=\{e\}\); (2) \(h_1h_2=h_2h_1\) for all \(h_1\in H_1\), \(h_2\in H_2\); (3) \(G=H_1H_2\), that is every \(g\in G\) is some \(h_1h_2\). Then \(G\cong H_1\times H_2\).

Proof. Let \(\Phi:H_1\times H_2\to G\), \((h_1,h_2)\mapsto h_1h_2\). Homomorphism: \(\Phi(h_1,h_2)\Phi(h_1',h_2')=h_1h_2h_1'h_2'=h_1h_1'h_2h_2'=\Phi\big((h_1,h_2)(h_1',h_2')\big)\), using (2). Surjective: this is (3). Injective: if \(h_1h_2=e\), then \(h_2=h_1^{-1}\in H_1\cap H_2=\{e\}\) by (1), so \(h_1=h_2=e\) and \(\ker\Phi\) is trivial. \(\blacksquare\)

Remark. If \(H_1\cap H_2=\{e\}\) then \(|H_1H_2|=|H_1||H_2|\). So when \(|H_1||H_2|=|G|\), condition (1) implies (3).

Klein four-group

\(K_4=C_2\times C_2\). Every element satisfies \((a,b)^2=(e,e)\), so every element has order at most \(2\). In particular \(K_4\not\cong C_4\).

Groups of order 4

If \(|G|=4\), then \(G\cong C_4\) or \(G\cong K_4\).

Proof. By Lagrange, each non-identity element has order \(2\) or \(4\). If some element has order \(4\), then \(G\cong C_4\). Otherwise every non-identity element has order \(2\). Take distinct non-identity \(a,b\) and let \(H_1=\langle a\rangle\), \(H_2=\langle b\rangle\). Then \(H_1\cap H_2=\{e\}\), and since \(|H_1||H_2|=4=|G|\), the remark gives \(G=H_1H_2\). Also \(ab\neq e\) (else \(b=a^{-1}=a\)), so \(o(ab)=2\): \(abab=e\), which gives \(ab=ba\). By the direct product theorem, \(G\cong C_2\times C_2=K_4\). \(\blacksquare\)

Chinese remainder theorem

If \(\gcd(m,n)=1\), then \(C_m\times C_n\cong C_{mn}\).

Proof. Let \(C_{mn}=\langle g\rangle\), \(H_1=\langle g^n\rangle\) and \(H_2=\langle g^m\rangle\). Since \(o(g)=mn\), \(g^n\) has order \(m\) and \(g^m\) has order \(n\), so \(H_1\cong C_m\) and \(H_2\cong C_n\). Check the direct product theorem: (1) \(g^k\in H_1\iff g^k=g^{np}\) for some \(p\iff k\equiv np\pmod{mn}\) for some \(p\iff n\mid k\). Similarly \(g^k\in H_2\iff m\mid k\). So \(g^k\in H_1\cap H_2\) means \(n\mid k\) and \(m\mid k\), and since \(\gcd(m,n)=1\) this gives \(mn\mid k\), that is \(g^k=e\). So \(H_1\cap H_2=\{e\}\). (2) holds because \(C_{mn}\) is abelian. (3) follows from (1) and the remark, since \(|H_1||H_2|=mn\). Hence \(C_{mn}\cong H_1\times H_2\cong C_m\times C_n\). \(\blacksquare\)

Groups of order 6

If \(|G|=6\), then \(G\cong C_6\) or \(G\cong D_6\).

Proof. By Cauchy's theorem there are \(r,s\in G\) with \(o(r)=3\), \(o(s)=2\). Then \([G:\langle r\rangle]=2\) and \(s\notin\langle r\rangle\), so \(s\langle r\rangle=G\setminus\langle r\rangle=\langle r\rangle s\). Hence \(sr=r^is\) for some \(i\in\{0,1,2\}\). If \(i=0\), then \(sr=s\), so \(r=e\), impossible. If \(i=1\), then \(sr=rs\), and \(\langle r\rangle,\langle s\rangle\) satisfy the direct product theorem, so \(G\cong C_3\times C_2\cong C_6\). If \(i=2\), then \(sr=r^{-1}s\) with \(r^3=s^2=e\): these are the dihedral relations, so \(G\cong D_6\). \(\blacksquare\)

Remark. \(S_3\) is a non-abelian group of order \(6\), so \(S_3\cong D_6\).

Quaternion group

\(Q_8=\{\pm1,\pm i,\pm j,\pm k\}\), realised by the matrices $$1=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad i=\begin{pmatrix}i&0\\0&-i\end{pmatrix},\quad j=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\quad k=\begin{pmatrix}0&i\\i&0\end{pmatrix}$$ and their negatives, under matrix multiplication. The relations are \(i^2=j^2=k^2=-1\), \(ij=k\), \(jk=i\), \(ki=j\), and \(-1\) commutes with everything.

Since \(ji=-k\neq ij\), \(Q_8\) is non-abelian. It is not \(\cong D_8\): \(Q_8\) has one element of order \(2\) (namely \(-1\)), while \(D_8\) has five (the \(180^\circ\) rotation and four reflections).

Groups of order 8

If \(|G|=8\), then \(G\) is isomorphic to one of \(C_8\), \(C_4\times C_2\), \(C_2\times C_2\times C_2\), \(D_8\) or \(Q_8\).

Proof. By Lagrange, element orders are \(1,2,4\) or \(8\). If some element has order \(8\), then \(G\cong C_8\). If every non-identity element has order \(2\), then \(G\) is abelian (as in order \(4\)). Choosing \(a\neq b\) and \(c\notin\{e,a,b,ab\}\) and applying the direct product theorem twice gives \(G\cong\langle a\rangle\times\langle b\rangle\times\langle c\rangle\cong C_2\times C_2\times C_2\).

Otherwise take \(a\) with \(o(a)=4\) and \(b\notin\langle a\rangle\). Since \([G:\langle a\rangle]=2\), \(b\langle a\rangle=G\setminus\langle a\rangle=\langle a\rangle b\), so \(ba=a^ib\) for some \(i\). \(i=0\) gives \(a=e\); \(i=2\) gives \(bab^{-1}=a^2\), but conjugates have equal order and \(o(a^2)=2\neq4\). So \(i=1\) (\(G\) abelian, case A) or \(i=3\) (\(ba=a^{-1}b\), case B). Next, \(b^2\in\langle a\rangle\): otherwise \(b^2=ba^j\) for some \(j\), giving \(b=a^j\in\langle a\rangle\). And \(b^2\neq a^{\pm1}\), since then \(o(b)=8\). So \(b^2=e\) (case I) or \(b^2=a^2\) (case II).

A, I: \(\langle a\rangle\cap\langle b\rangle=\{e\}\), so \(G\cong C_4\times C_2\). A, II: \(c=ab^{-1}\) has \(c^2=a^2b^{-2}=e\) and \(c\notin\langle a\rangle\), so again \(G\cong\langle a\rangle\times\langle c\rangle\cong C_4\times C_2\). B, I: \(o(a)=4\), \(o(b)=2\), \(ba=a^{-1}b\): the dihedral relations, so \(G\cong D_8\). B, II: \(b^2=a^2\), \(ba=a^{-1}b\). Setting \(i=a\), \(j=b\), \(k=ab\), \(-1=a^2\), the elements \(e,a,a^2,a^3,b,ab,a^2b,a^3b\) are \(\pm1,\pm i,\pm j,\pm k\) with the relations of \(Q_8\), so \(G\cong Q_8\). \(\blacksquare\)

Summary. Groups of order up to \(8\): \(1\); \(C_2\); \(C_3\); \(C_4,\ C_2\times C_2\); \(C_5\); \(C_6,\ D_6\); \(C_7\); \(C_8,\ C_4\times C_2,\ C_2\times C_2\times C_2,\ D_8,\ Q_8\).
