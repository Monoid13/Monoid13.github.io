Countable and uncountable sets

Countable. A set \(X\) is countable if it is finite or in bijection with \(\mathbb N\). Equivalently, there is an injection \(X\to\mathbb N\).

Summary: showing \(X\) is countable. Do one of the following:

  1. List its elements as \(x_1,x_2,x_3,\dots\), so every element appears somewhere in the list.
  2. Inject it into \(\mathbb N\), or into any set already known to be countable.
  3. Use that a countable union of countable sets is countable (6.8): write \(X=\bigcup_{n\in\mathbb N}X_n\) with each \(X_n\) countable.
  4. If \(X\) is near \(\mathbb R\), consider \(\mathbb Q\): inject \(X\) into \(\mathbb Q\). For example, a family of disjoint open intervals in \(\mathbb R\) is countable, since choosing a rational in each interval is an injection into \(\mathbb Q\).

Summary: showing \(X\) is uncountable. Do one of the following:

  1. Use a diagonal argument: given any list \(x_1,x_2,\dots\) of elements of \(X\), build an element that differs from each \(x_n\) in its \(n\)-th place, so no list covers \(X\).
  2. Inject any uncountable set into \(X\): if \(Y\) is uncountable and \(Y\to X\) is injective, then \(X\) is uncountable (otherwise \(Y\) would inject into \(\mathbb N\)).
