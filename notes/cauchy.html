Cauchy's theorem

Theorem 4.13 (Cauchy's theorem). If \(|G|<\infty\) and \(p\) is a prime dividing \(|G|\), then there is \(g\in G\) with \(o(g)=p\).

Why it matters. Lagrange says the order of every element divides \(|G|\). The converse is false in general: \(|A_4|=12\), but \(A_4\) has no element of order \(6\). Cauchy's theorem says the converse does hold for primes. For example, \(|D_{10}|=10\), so \(D_{10}\) has an element of order \(2\) (a reflection) and one of order \(5\) (a rotation).

Step 1: build a set. Let $$X=\{(g_1,\dots,g_p): g_i\in G,\ g_1g_2\cdots g_p=e\}.$$ Choosing \(g_1,\dots,g_{p-1}\) freely forces \(g_p=(g_1\cdots g_{p-1})^{-1}\), so \(|X|=|G|^{p-1}\). This is divisible by \(p\), since \(p\mid|G|\).

Step 2: let \(C_p\) rotate the tuples. Write \(C_p=\{1,t,\dots,t^{p-1}\}\) and let \(t^k(g_1,\dots,g_p)=(g_{k+1},\dots,g_p,g_1,\dots,g_k)\). Then \(t^kt^l=t^{k+l}\). The rotated tuple is still in \(X\): with \(a=g_1\cdots g_k\) and \(b=g_{k+1}\cdots g_p\), we have \(ab=e\), so \(b=a^{-1}\) and \(ba=e\). So this is an action of \(C_p\) on \(X\).

Step 3: orbits have size \(1\) or \(p\). By orbit–stabiliser, each orbit's size divides \(|C_p|=p\). Since \(p\) is prime, every orbit has size \(1\) or \(p\).

Step 4: count. Let \(\ell\) be the number of orbits of size \(1\) and \(m\) the number of size \(p\). The orbits partition \(X\), so $$|G|^{p-1}=|X|=\ell+pm .$$ The left side is divisible by \(p\), so \(p\mid\ell\).

Step 5: find the element. An orbit of size \(1\) is a tuple fixed by rotation, so all its entries are equal: \((g,g,\dots,g)\) with \(g^p=e\). The tuple \((e,\dots,e)\) is one of these, so \(\ell\ge1\). Since \(p\mid\ell\), in fact \(\ell\ge p\ge2\), so there is another, \((g,\dots,g)\) with \(g\neq e\) and \(g^p=e\). Then \(o(g)\) divides \(p\) and is not \(1\), so \(o(g)=p\). \(\blacksquare\)

The idea in one line. Counting the solutions of \(g_1\cdots g_p=e\) modulo \(p\) shows that \(g=e\) cannot be the only constant solution.
