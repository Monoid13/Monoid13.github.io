Burnside's lemma

Setting. Let a finite group \(G\) act on a finite set \(X\). Write \(\mathcal O\) for the set of orbits, and for \(g\in G\) let \(\operatorname{Fix}(g)=\{x\in X : gx=x\}\) be the set of points fixed by \(g\).

Lemma (Burnside). The number of orbits is the average number of fixed points: $$|\mathcal O|=\frac{1}{|G|}\sum_{g\in G}|\operatorname{Fix}(g)| .$$

Step 1: count fixed pairs two ways. Let \(S=\{(g,x)\in G\times X : gx=x\}\). Counting by \(g\) first, then by \(x\) first, $$|S|=\sum_{g\in G}|\operatorname{Fix}(g)|=\sum_{x\in X}|\operatorname{Stab}_G(x)| .$$

Step 2: use orbit–stabiliser. By Corollary 4.10, \(|G|=|Gx|\,|\operatorname{Stab}_G(x)|\), so \(|\operatorname{Stab}_G(x)|=\dfrac{|G|}{|Gx|}\) and $$\sum_{g\in G}|\operatorname{Fix}(g)|=\sum_{x\in X}\frac{|G|}{|Gx|} .$$

Step 3: sum orbit by orbit. The orbits partition \(X\), so the sum splits into one sum per orbit. For every \(x\in O\), the orbit of \(x\) is \(O\) itself, so \(|Gx|=|O|\). Therefore $$\sum_{x\in X}\frac{|G|}{|Gx|}=\sum_{O\in\mathcal O}\sum_{x\in O}\frac{|G|}{|O|}=\sum_{O\in\mathcal O}|O|\,\frac{|G|}{|O|}=\sum_{O\in\mathcal O}|G|=|G|\,|\mathcal O| .$$

Conclusion. Combining the steps, \(\sum_{g\in G}|\operatorname{Fix}(g)|=|G|\,|\mathcal O|\). Dividing by \(|G|\) gives $$|\mathcal O|=\frac{1}{|G|}\sum_{g\in G}|\operatorname{Fix}(g)|. \qquad\blacksquare$$

Example: colouring a die. Each of the 6 faces of a cube is painted one of 3 colours (colours may repeat). Two colourings count as the same if one can be rotated into the other. How many different dice are there?

The action. The rotation group \(G\) of the cube has \(|G|=24\) and acts on the \(3^6=729\) colourings. Different dice are exactly the orbits, so by Burnside's lemma we need \(|\operatorname{Fix}(g)|\) for each rotation \(g\).

Fixed colourings. A rotation fixes a colouring exactly when each cycle of faces it permutes is a single colour. So a rotation with \(c\) face-cycles fixes \(3^{c}\) colourings.
